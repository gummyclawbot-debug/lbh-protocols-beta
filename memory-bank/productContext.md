# Product context

## Why this exists
Pharmacy workflows often require switching between calculations, dosing references, formulary rules, and handling restrictions. LBH Protocols Beta consolidates these into one fast institutional reference surface with a shared patient profile.

## Experience goals
- Immediate orientation: patient inputs remain visible while tools change.
- Fast recognition: clear calculator names and clinically meaningful units.
- Dark/light usability and responsive layouts.
- Explicit limitations and source/version visibility rather than implied authority.
- Safe errors and boundary handling; never silently produce plausible nonsense.

## Trust model
The application supports clinical work but must not overstate validation. Current content should be treated as a rebuild requiring reconciliation with authoritative LBH policy. Visual quality and passing software tests do not constitute clinical approval.
